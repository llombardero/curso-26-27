# Despliegue de MiniJarvis en Moodle

1. Publica los recursos HTML de forma progresiva conforme avance el reto; no expongas ejemplos privados ni soluciones completas.
2. Crea una tarea por H0-H7 y HF a partir de `02-PROFESORADO/05-ECOSISTEMA-DIGITAL/TAREAS-MOODLE/`.
3. Registra una sola vez los enlaces estables de diario, Scrum, GitHub y Sites.
4. En H0 solicita Scrum, torre no-code si procede y ticket individual; no GitHub ni Sites.
5. En H1-H7 solicita tag/commit estable, confirmación de diario/Scrum y evidencia no-code solo si existe.
6. En HF añade release/tag, los dos Sites y defensa; la recuperación se asigna únicamente a quien la necesite.
7. No solicites copiar README, capturas rutinarias, registros IA separados ni exportaciones PDF/XLSX sin necesidad concreta.

Moodle distribuye instrucciones, registra la versión entregada y conserva feedback. GitHub conserva el producto técnico; Drive no replica Moodle ni el repositorio.
