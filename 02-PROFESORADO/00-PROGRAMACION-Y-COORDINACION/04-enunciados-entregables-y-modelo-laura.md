# Enunciados, entregas y evaluación operativa

## Modelo simplificado

El repositorio GitHub y su README son el eje técnico desde H1. El diario conserva proceso individual significativo; Scrum, proceso colectivo; Drive, evidencia no-code excepcional; Sites, selección C1/C2/HF; Moodle, versión entregada y feedback; la defensa, autoría y comprensión.

| Tramo | Núcleo evaluable | Evidencia canónica |
|---|---|---|
| H0 | Trabajo en equipo y ciclo Scrum | HADA privada, ticket individual, Scrum, torre no-code, review/retro; sin GitHub/Sites. |
| H1 | Estructura, variables, constantes, entrada/salida | Código, README, pruebas, historial y defensa. |
| H2 | Control de flujo, bucles y depuración | Código/tests y depuración compacta en README. |
| H3 | Colecciones y casos límite | Código/tests y decisión de colección en README. |
| C1 | Síntesis H1-H3 | Sites, defensa y recuperación solo de carencias. |
| H4 | POO y diseño de clases | Código/tests, diagrama de clases y relación diagrama-código. |
| H5 | Interfaces, extensibilidad, clean code y patrón | Código/tests, historial/PR y README. |
| C2 | Síntesis H4-H5 | Sites, defensa y recuperación solo de carencias. |
| H6 | Ficheros, persistencia, logs y seguridad | Código/tests, datos ficticios, configuración segura y README reproducible. |
| H7 | IA responsable | Código/configuración, trazabilidad y validación distribuida en README, código, diario/Scrum y defensa. |
| HF | Producto integrado y comunicación | Release/tag, README, Sites y defensa. |

Una evidencia puede cubrir varias fases HEXA. No se penaliza la ausencia de formularios redundantes. Para recuperar, se exige únicamente la evidencia concreta que falta. La comparación Java-Python se mantiene como actividad de transferencia, no como informe repetido. El diagrama de comportamiento H4 se considera práctica opcional coordinada de ED RA6, no evidencia obligatoria de Programación.

La matriz curricular `01-matriz-integrada-ra-ce-evidencias-tareas.md` mantiene la trazabilidad normativa; esta tabla define la operación cotidiana.
