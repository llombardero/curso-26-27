# Protocolo de entrega y congelación

- H0: localizar Scrum, torre no-code si procede y ticket individual final; sin GitHub ni Sites.
- H1-H7: entregar tag `hN-entrega` o commit estable y confirmar que diario/Scrum están actualizados. Adjuntar evidencia no-code solo si existe.
- HF: release/tag final, Sites personal y de equipo, defensa y recuperación solo si corresponde.

GitHub se congela por commit/tag. Sheets y Sites mantienen su fuente viva y el profesorado registra el momento evaluado. PDF/XLSX solo si se solicita expresamente por una necesidad concreta. Reparar un permiso o enlace no obliga a rehacer el producto.
