# Protocolo de entrega y congelación

## Entrega en Moodle

Cada tarea solicita enlaces concretos y una identificación estable de la evidencia:

- URL del Site personal o de equipo;
- URL del archivo o pestaña necesaria;
- URL de GitHub cuando corresponda;
- commit, tag o release en H1 y siguientes;
- fecha y hora declarada por el equipo;
- exportación PDF/XLSX cuando la evidencia siga siendo editable.

## Congelación

1. El equipo termina la evidencia.
2. Comprueba permisos con vista de lector.
3. Exporta a PDF o XLSX los apartados evaluables.
4. Guarda la exportación en `03_EXPORTACIONES_CERRADAS/HN/`.
5. Nombra el archivo con hito, equipo y evidencia.
6. Entrega en Moodle la URL viva y la exportación cerrada.
7. El profesorado verifica enlaces y registra feedback en Moodle.

## GitHub

Para el código no se usa una copia ZIP como referencia principal. Se entrega un commit o tag. Ejemplo:

```text
Repositorio: https://github.com/organizacion/equipo-01-minijarvis
Versión evaluada: h1-entrega
Commit: identificador visible en GitHub
```

## Incidencias

Si un enlace falla, Moodle conserva la entrega y se registra la corrección del permiso. No se acepta sustituir silenciosamente la evidencia por otra creada después de la fecha límite.
