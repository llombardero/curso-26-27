# Plantilla del Site de equipo

## Función

El Site de equipo comunica el incremento y permite localizar las evidencias. No replica el backlog, el diario, el repositorio ni el README.

## Navegación

```text
Inicio
├── Equipo y acuerdos
├── H0 — Torre, review y retrospectiva
├── H1 — Primer MiniJarvis
└── Demo final
```

## Página H1

1. Reto e incremento en tres líneas.
2. Dos decisiones principales, con enlace a commit, README o fila Scrum.
3. Prueba normal y prueba alternativa, con resultado y enlace profundo.
4. Versión evaluada del repositorio (`h1-entrega` o commit).
5. Enlace restringido a la pestaña H1 del Sheet Scrum.
6. Review: qué cumple y qué queda fuera.
7. Retrospectiva: una mejora concreta para H2.

## Regla de evidencia única

Drive, Sheets y GitHub conservan los originales. El Site solo selecciona, explica y enlaza. No se pegan tablas completas ni se sube otra copia del código.

## Privacidad

- Publicación `Restringido` al dominio o grupo autorizado.
- Sin credenciales, datos personales, calificaciones ni puntuaciones privadas.
