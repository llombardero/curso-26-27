# Modelos visuales Google Sites — H1

Los HTML `06-Google-Site-personal-H1-modelo.html` y `07-Google-Site-equipo-H1-modelo.html` son modelos visuales. No se importan automáticamente en Google Sites.

1. Abre el HTML correspondiente en el navegador.
2. Crea un Site en blanco con la cuenta institucional.
3. Replica navegación y bloques siguiendo `03-Site-personal-estructura.md` o `04-Site-equipo-estructura.md`.
4. Sustituye ejemplos por enlaces profundos a GitHub, README, diario o Scrum.
5. Mantén borrador y publicación como **Restringido**.
6. Prueba los permisos con otra cuenta autorizada.

No copies el diario, Scrum o README dentro del Site. El modelo visual sirve para presentar una selección, no para crear otra fuente.
