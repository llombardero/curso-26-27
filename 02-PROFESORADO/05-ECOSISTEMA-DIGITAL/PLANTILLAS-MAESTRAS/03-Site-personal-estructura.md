# Plantilla del Site personal

## Función

El Site personal es una **selección razonada** de evidencias. No sustituye al diario ni lo copia: explica qué demuestra una evidencia profunda y enlaza a su fuente.

## Navegación

```text
Inicio
├── H0 — Cómo trabajo en equipo
├── H1 — Mi primer MiniJarvis
└── Portfolio final
```

## Página H1

1. Mi aportación verificable: acción, resultado y enlace profundo.
2. Concepto del Tema 1 que ahora puedo explicar.
3. Problema significativo y decisión tomada; enlazar al diario si hace falta detalle.
4. Prueba seleccionada y qué demuestra.
5. Qué parte puedo ejecutar, modificar y defender.
6. Uso de IA relevante y validación; enlazar al diario, no copiar el registro.
7. Siguiente mejora concreta para H2.

## Fuente de cada dato

| Contenido del Site | Fuente original |
|---|---|
| Código, commits y ejecución | GitHub y README |
| Proceso individual e IA personal | Diario individual |
| Proceso de equipo | Sheet Scrum |
| Decisiones y pruebas colectivas | GitHub, README o Scrum |

## Límites

- No mostrar apellidos de compañeros, puntuaciones HADA ni feedback privado.
- No insertar secretos, credenciales o datos personales.
- No pegar todo el diario: seleccionar una evidencia, enlazarla y explicar por qué demuestra aprendizaje.
- Mantener el borrador y el sitio publicado como `Restringido`.
