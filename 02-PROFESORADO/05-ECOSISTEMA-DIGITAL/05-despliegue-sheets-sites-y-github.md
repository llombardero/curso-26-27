# Despliegue de Sheets, Sites y GitHub

## Por estudiante

1. Crear una copia institucional del diario.
2. Compartirla con el profesorado.
3. Crear Site personal restringido con páginas Inicio, H0–H7 y HF.
4. Probar lectura docente.

## Por equipo

1. El profesorado crea el Sheet Scrum desde la plantilla maestra.
2. El profesorado crea el Site de equipo y añade editores.
3. Guardar sus enlaces en `00_ENLACES`.
4. En H1 crear o asignar el repositorio GitHub y guardar su URL.
5. Probar cada enlace con una cuenta no propietaria.

## En cada hito

Actualizar diario, sprint, decisiones, bloqueos, review, retrospectiva y páginas del Site. Desde H1 crear tag/commit de entrega. Moodle recibe enlaces profundos y exportaciones cerradas.
