# Modelo HEXA aplicado a MiniJarvis

## Fuente metodológica canónica

La base metodológica de este proyecto es [`Modelo_HEXA_COMPLETO.pdf`](Modelo_HEXA_COMPLETO.pdf).

Este documento operativo no redefine el modelo: concreta su aplicación a MiniJarvis. Si aparece una discrepancia, prevalece el PDF canónico.

## Estructura oficial

### Fase 0 — Equipos

Es la base transversal del modelo, no una de las seis fases del ciclo. Antes y durante el reto se configuran equipos equilibrados, roles, normas, colaboración y herramientas de organización. En MiniJarvis se concreta mediante HADA, funciones revisables, Scrum de aula, Kanban y acuerdos de equipo.

### Las seis fases

1. Activar — entender el reto
   - Presentar una situación real o verosímil, su propósito, objetivos, límites y criterios.
   - Evidencia de salida: comprensión compartida del reto.

2. Investigar — aprender lo necesario
   - Buscar, contrastar y adquirir los conocimientos imprescindibles mediante investigación guiada y micropíldoras docentes.
   - Evidencia de salida: base conceptual suficiente y preguntas resueltas para decidir.

3. Idear — proponer soluciones
   - Generar alternativas, debatirlas y seleccionar una propuesta viable con criterios explícitos.
   - Evidencia de salida: solución elegida y argumentada.

4. Planificar — organizar el trabajo
   - Convertir la idea en tareas, tiempos, responsabilidades, hitos y criterios de seguimiento.
   - Evidencia de salida: plan de acción visible en backlog, tablero o documento equivalente.

5. Ejecutar — crear
   - Construir, probar y mejorar iterativamente el producto o solución.
   - Evidencia de salida: producto funcional y pruebas observables.

6. Comunicar — evaluar y reflexionar
   - Presentar el producto, evaluar proceso y resultado, realizar autoevaluación y coevaluación y formular mejoras.
   - Evidencia de salida: defensa, evaluación, reflexión y siguiente paso.

## Reglas de aplicación

- El ciclo completo pertenece al reto o hito; una sesión puede desarrollar una fase o una transición explícita entre fases.
- El orden de referencia es Activar → Investigar → Idear → Planificar → Ejecutar → Comunicar.
- Volver a una fase anterior por nueva evidencia no invalida el ciclo: hace visible su carácter iterativo.
- La instrucción docente guiada se sitúa principalmente en Investigar y también puede aparecer durante Ejecutar para desbloquear.
- Prototipar no sustituye a Planificar; documentar no sustituye a Comunicar.
- Comunicar incluye evaluación y reflexión. No se añade una séptima fase independiente llamada “Reflexionar”.
- Los antiguos códigos H, E, X y A no son fases del Modelo HEXA canónico y no deben utilizarse como taxonomía metodológica.

## Evidencias mínimas del ciclo

Un hito no completa el ciclo solo porque exista código. Debe conservar evidencia de:

1. comprensión del reto;
2. conocimiento investigado o explicado;
3. alternativas y decisión;
4. planificación visible;
5. producto y pruebas;
6. comunicación, evaluación y reflexión.

Si falta una fase, se recuperan esa fase y su evidencia; no se repite automáticamente todo el hito.
