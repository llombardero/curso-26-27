# MiniJarvis — materiales del profesorado

Edición final para Moodle — curso 2026/2027.

- `00-PROGRAMACION-Y-COORDINACION/`: planificación, RA/CE, calendario, evaluación y mapa curricular.
- `01-GUIAS-POR-HITO/`: guías docentes y listas de comprobación.
- `02-SESIONES/`: guías operativas para cada clase.
- `03-PRESENTACIONES/`: presentación inicial, presentaciones H0 seleccionadas y colección `POR-SESION/` con una presentación para cada una de las 106 sesiones.
- `04-RECURSOS-NORMATIVOS-Y-TEMARIOS/`: normativa y referencias.
- `05-ECOSISTEMA-DIGITAL/`: Drive, Sheets, Sites, GitHub y tareas Moodle H0–HF.

## Base metodológica HEXA

- `04-RECURSOS-NORMATIVOS-Y-TEMARIOS/Modelo_HEXA_COMPLETO.pdf`: fuente metodológica canónica.
- `04-RECURSOS-NORMATIVOS-Y-TEMARIOS/Modelo_HEXA_APLICADO_A_MINIJARVIS.md`: concreción operativa de la Fase 0 Equipos y de las seis fases Activar, Investigar, Idear, Planificar, Ejecutar y Comunicar.

Las guías, sesiones, rúbricas y presentaciones deben usar los nombres completos de estas fases. Los códigos H–E–X–A de cuatro fases quedan obsoletos.

## Autoridad documental

Esta relación aclara qué documento resuelve cada tipo de discrepancia; no crea normativa nueva:

1. La normativa y las programaciones didácticas aprobadas determinan las decisiones curriculares formales.
2. `04-RECURSOS-NORMATIVOS-Y-TEMARIOS/Modelo_HEXA_COMPLETO.pdf` define la metodología.
3. `04-RECURSOS-NORMATIVOS-Y-TEMARIOS/Modelo_HEXA_APLICADO_A_MINIJARVIS.md` concreta su implementación en MiniJarvis.
4. El mapa maestro y la matriz RA/CE mantienen la planificación y la trazabilidad.
5. La ficha de cada hito fija su contrato operativo; para H1 es `../01-ALUMNADO/02-HITOS/h1-primer-asistente/13B-ficha-alumnado-h1-primer-asistente.md`.
6. Las sesiones desarrollan la secuencia y las guías aportan apoyo sin ampliar ese contrato.
7. HTML, PPTX, PDF y ZIP son derivados de las fuentes editables correspondientes.

Esta carpeta es privada. No debe publicarse completa en el aula del alumnado.
