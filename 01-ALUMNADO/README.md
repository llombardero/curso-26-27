# MiniJarvis — materiales del alumnado

Edición final para Moodle — curso 2026/2027.

## Orden de uso

1. `00-EMPIEZA-AQUI/`: proyecto, ecosistema digital, entregables, evaluación y uso responsable de IA.
2. `01-LIBRO-POR-HITOS/`: capítulos que publica progresivamente el profesorado.
3. `02-HITOS/`: reto, plantillas y ficha de entrega digital de H0–H7 y HF.
4. `03-SESIONES/`: ficha de trabajo de cada clase.
5. `04-PLANTILLAS-GLOBALES/`: modelos transversales y estructuras de Sites/Moodle.

Si no has usado antes Drive o GitHub, empieza también por:

- `00-EMPIEZA-AQUI/14-guia-basica-drive-alumnado.md`.
- `00-EMPIEZA-AQUI/15-guia-basica-github-alumnado.md`.

## Regla de trabajo

Moodle indica qué hacer y registra la entrega. Drive conserva evidencias, Sheets registra el proceso, Sites selecciona aprendizajes y GitHub conserva el código. No mantengas dos copias editables del código.

Los ejemplos resueltos de Laura no están aquí: se mostrarán después del intento propio o de una primera versión defendible.
