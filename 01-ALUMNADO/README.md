# MiniJarvis - materiales del alumnado

## Cómo trabajar

1. Consulta en Moodle el reto o la sesión que esté activa.
2. Lee solo los capítulos y plantillas indicados para ese momento.
3. Usa la guía básica de Drive o GitHub si necesitas ayuda con esas herramientas.
4. Revisa los criterios antes de empezar y las instrucciones de entrega antes de enviar.

## Regla de trabajo

Moodle indica qué hacer y registra la entrega. Drive conserva evidencias, Sheets registra el proceso, Sites selecciona aprendizajes y GitHub conserva el código. No mantengas dos copias editables del código.

Los ejemplos resueltos se mostrarán después del intento propio o de una primera versión defendible.
