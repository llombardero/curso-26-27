# Qué entregar y dónde

| Evidencia | Lugar canónico |
|---|---|
| Código, tests, historial, diagramas ligados al código y versión evaluada | GitHub desde H1 |
| Ejecución, pruebas, decisiones técnicas, incidencias, refactorización, persistencia y seguridad | README del proyecto |
| Aprendizaje y proceso individual significativo | Un único diario individual |
| Backlog, decisiones, bloqueos, review, retrospectiva e IA colectiva | Un único Scrum de equipo |
| Fotografías o evidencia no-code sin lugar mejor | Drive, de forma excepcional |
| Selección y comunicación | Sites en C1, C2 y HF |
| Entrega oficial y feedback | Moodle |
| Autoría y comprensión | Defensa |

No hay una plantilla por sesión ni un portfolio por hito. La comparación Java-Python se conserva como actividad y puede registrarse en diario/portfolio. Los enlaces estables se dan una vez. H0 no exige GitHub ni Sites; HF no exige documentos paralelos para demo, defensa, IA o mejora. Si falta algo, recupera únicamente esa evidencia.
