Entrega digital — H1

Qué debes entregar en Moodle

La entrega de H1 identifica la versión de MiniJarvis que quieres que se evalúe.

Indica:

Tag: h1-entrega

o, si no se utiliza el tag:

Commit estable: <identificador del commit>

Esa versión debe corresponder con el programa que puedes ejecutar, explicar y defender.

Antes de entregar

Comprueba:

[ ] La versión indicada es la que quiero presentar.
[ ] El programa se ejecuta.
[ ] El README del proyecto permite saber qué hace y cómo ejecutarlo.
[ ] Los enlaces estables al diario y Scrum siguen siendo válidos.
[ ] Diario y Scrum están actualizados si durante H1 hubo algo significativo que registrar.
[ ] Puedo explicar y modificar el código de esta versión.

No tienes que escribir en el diario o Scrum solo para completar esta lista.

Qué NO debes volver a subir

Moodle no necesita otra copia de información que ya está correctamente conservada en su fuente canónica.

No subas de forma rutinaria:

  • una copia del código;
  • una copia del README;
  • capturas de la consola;
  • capturas del repositorio;
  • tablas independientes de pruebas;
  • informes de ejecución;
  • documentos para la defensa;
  • un registro independiente de IA;
  • copias del diario o Scrum;
  • exportaciones PDF o XLSX;
  • enlaces estables que ya fueron proporcionados.

La defensa se realiza sobre el producto y las evidencias reales.

Evidencia no-code excepcional

Añade un archivo en Moodle únicamente si H1 ha generado una evidencia necesaria que:

  1. no sea código;
  2. deba conservarse para la evaluación;
  3. no tenga ya una fuente canónica adecuada.

Si no existe esa evidencia excepcional, no añadas ningún archivo extra.

Uso de IA

No se entrega un registro de IA independiente.

Si la IA tuvo una intervención significativa en el trabajo evaluable, su trazabilidad debe estar ya integrada en:

  • el diario individual, si corresponde al aprendizaje o trabajo individual;
  • Scrum, si corresponde a una decisión significativa del equipo.

Las consultas triviales no requieren registro.

Entrega mínima de H1

En condiciones normales, la entrega queda reducida a:

versión evaluada
       +
confirmación de fuentes estables
       +
evidencia no-code solo si realmente existe

No dupliques evidencias para demostrar que existen.

Idea clave

Moodle identifica la entrega.
El repositorio conserva el producto.
Las demás evidencias permanecen en su fuente canónica.
