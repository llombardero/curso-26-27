Inicio alumnado

Libro del alumnado - Programación con MiniJarvis

Este libro acompaña el proyecto anual. Cada capítulo se publica cuando es necesario para construir el hito activo.

MiniJarvis crece así:

programa básico -> menú -> memoria -> clases -> herramientas -> persistencia -> IA responsable -> portfolio final

Cómo usar cada capítulo

  1. Lee el objetivo y los conceptos básicos.
  2. Reproduce los ejemplos pequeños.
  3. Aplica lo aprendido a MiniJarvis.
  4. Registra pruebas, errores y decisiones.
  5. Comprueba que puedes explicarlo con tus palabras.

Los ejemplos resueltos sirven para comparar y mejorar después del intento propio, no para copiar antes de pensar.

Los PDF temáticos complementarios se publican de forma individual cuando el avance del reto los hace necesarios; no forman parte del paquete HTML completo disponible desde el inicio.
